# GIM – Gimnasio Club Atlético Adrogué

Web estática (HTML + CSS + JS vanilla, sin build). Se abre con doble clic en `index.html` o se publica en GitHub Pages.

- **Todo el contenido** (textos, horarios, servicios, curso, tienda, equipo, galería, testimonios, FAQ) está en `data.js` → objeto `CONFIG`.
- Lo marcado `// PENDIENTE CLIENTE` falta confirmar o reemplazar.
- Imágenes en `/img` (WebP, nombres en minúscula sin tildes ni espacios). Fuentes locales en `/fonts`.
- Título, descripción y Open Graph están en `index.html` (las redes no leen JS).

Web hecha por [Vigolo Web Studio](https://vigolowebstudio.com).
